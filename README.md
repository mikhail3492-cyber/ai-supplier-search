# AI Supplier Search — поиск поставщиков в Китае

Практический инструмент для **первичного поиска поставщиков товаров в Китае с применением ChatGPT**. По заполненной заявке и фотографиям товара выполняется поиск компаний преимущественно на **Alibaba**, при необходимости — на **1688**. Результат — Excel-таблица по установленному шаблону и краткий закупочный бриф.

## Как начать работу

1. **Настройте ветку ChatGPT.** Создайте отдельный чат или проект, добавьте инструкцию из `prompts/Промт_Поиск поставщиков.docx`, входной Excel-образец и шаблон результата. Приложите фотографии образца, они также нужны для первоначальной настройки. Файл в `examples/` показывает вид готового результата. Его добавлять для начальной настройки ветки не нужно. То есть первоначально настраиваем ветку, обучаем, чтобы впоследствии все работало без повторного промта.
Добавляем следующие файлы для настройки ветки:
Supplier_request_product list_Artificial palm tree leaves,
Suppliers_found_by_ChatGPT_Artificial_palm_tree_leaves,
Photo№1,
Photo№2,
Photo№3.
2. **Подайте новую заявку.** Заполните Excel по образцу `Supplier_request_product list_<товар>.xlsx` и загрузите его в настроенную ветку. При необходимости приложите фотографии искомого товара.
3. **Получите результат.** ChatGPT анализирует требования, ищет и отбирает доступные профили поставщиков, затем формирует Excel в исходном формате (до 10 компаний, если найдено достаточно подходящих) и краткий бриф.

Для работы необходим доступ ChatGPT к обработке Excel-файлов и актуальному веб-поиску. Для повторного поиска другого товара достаточно новой заполненной заявки и фотографий при наличии — **при условии, что инструкции и шаблон результата остаются доступны ветке ChatGPT**. Настройка по образцам не является дообучением самой модели.

## Файлы проекта

| Папка | Содержание |
|---|---|
| `prompts/` | Рабочий промпт с правилами поиска и заполнения Excel |
| `templates/` | Пример заполненной заявки и эталон оформления итоговой таблицы |
| `examples/` | Готовый пример поиска и фотографии демонстрационного товара |

## Основные правила

- В приоритете **Alibaba**, дополнительный источник — **1688**.
- Ссылки должны вести на **конкретные профили компаний**, а не на поисковую выдачу.
- Названия поставщиков и коммерческие показатели не должны выдумываться; неизвестные сведения отмечаются как **«Н/Д»**.
- Результат — **предварительный отбор**. Актуальность данных, условия закупки и надёжность компаний требуют дополнительной проверки.
